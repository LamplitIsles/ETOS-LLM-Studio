# iOS 聊天界面与键盘

CFL 聊天时间线使用 Exyte Chat 3.3.7 的 `ChatView` 展示消息列表并负责滚动，`inputViewBuilder` 返回空视图。会话模型负责发送和恢复，时间线投影生成可见行，列表适配负责 Exyte 与滚动；`CFLConversationView` 组装页面。ETOS 输入栏作为底部透明悬浮层复用消息、附件与语音入口，顶部设置是单独的悬浮控件。列表首尾为控件留出空间，消息滚动时可延伸到控件下方，列表上下边缘透明渐隐。`CFLComposerTextView` 用 `UIViewRepresentable` 包装 `UITextView`；业务发送与历史仍走 CFL。Kingfisher 8.15.0 是 iOS 直接依赖，供聊天动态图片显示使用；图片和其他媒体能力仍须分别验证，不能由键盘结果推断通过。

在线发送有效文字或图片时，本地行和本次草稿清除先于后台保存与提交；连续操作按顺序提交，同一操作使用同一身份。发送后、后台保存前如果进程突然终止，可能丢失尚未保存的内容。明确失败可在原消息处理；结果不明依原有持久记录核对，不自动重发。已知离线时保留输入。即时发送、确认前后视觉、图片预览和连续发送仍须在设备验证；此前未复现的键盘收起后跳动不能据此视为已修复。

## 输入焦点问题

曾出现点输入框后键盘立即收起：自定义输入的 `@FocusState` 没有与 UIKit 编辑状态同步，`updateUIView` 看到焦点为 `false` 后立即调用 `resignFirstResponder()`。未确认 `@FocusState` 未同步的根因，不要把它归因于某个特定手势或库。

当前实现由 `CFLConversationView` 持有普通 `@State`，通过 `Binding<Bool>` 传给输入框；`UITextViewDelegate` 在开始和结束编辑时回写，`updateUIView` 按同一状态协调 first responder。`CFLChatTableFocusBridge` 观察表格的点击和竖向拖动以收起焦点，并在拆除时移除观察和恢复表格设置；Exyte 同时配置了拖动收起键盘。

“外观 → 界面与交互 → 屏幕键盘”可选择右下角按键发送或换行，默认发送。选择换行时，输入非空文字后右侧加号变为发送箭头；仅有待发送图片时仍可从附件菜单发送。实体键盘设置独立。两种键盘模式、组合输入、草稿与图片以及消息响应时的行为尚需 iOS 设备验证。

用户对 v10 的真机反馈：输入框中央、下半区域各点击 3 次均可打开键盘；点击聊天空白或滑动收起后可以再次打开。诊断版的附件与语音入口正常。这些是针对当时交互的阶段性结果，不代表后续悬浮布局或聊天、媒体等所有真机功能均已验收。

调整输入或手势时，应在获准的设备测试中重复覆盖输入框不同位置、空白处及上下滑动后的再次打开，并检查附件、语音入口及消息控件没有被手势遮挡。构建和安装边界见 [iOS 构建与签名](ios-xcode-cloud.md)。

“外观 → 对话框视觉”可调整文字和语音消息气泡的圆角（0–36，默认 18）；关闭助手气泡时，助手文字与语音仍按原设置不显示背景。图片和表情保留各自的形状。此设置的保存、滑块效果和实际气泡外观尚需在 iOS 环境及设备验证。

“对话框视觉”顶部的聊天样例复用实际气泡和当前外观，助手样例包含 Markdown 和公式；返回本页后应反映生效的设置。CFL 助手消息会读取高级渲染器开关：普通 Markdown 继续使用原生排版，高级模式启用公式和 Mermaid 图；Mermaid 网页依赖外部资源。样例、开关与真实聊天的渲染一致性尚需设备验收。

### CFL 表情接入与验收

表情目录按需分页读取包、成员、名称或标签搜索及用户收藏；收藏状态以用户收藏分页为准。点击表情独立发送，保留输入文字和待发送图片；已有表情按素材 ID 收藏，普通聊天图片或 GIF 则从会话图片创建收藏。面板使用服务端保留透明度的 WebP 静态缩略图，已读取的目录页和图片保存在设备缓存，切换时先显示对应快照、后台核验，尚未读取的收藏页不能推断为未收藏。离线或核对失败时保留已有快照和图片，联网成功后按最新目录更新；目录明确标记不可用的表情不可发送。登录失效显示登录页但不删除磁盘缓存，重新登录同一服务后可复用。选中表情组时显示组名；按住表情时在触点上方显示带尖角的原图动效及名称，松手或取消后消失，滑动表情列表不发送；收藏通过独立按钮操作。聊天继续使用原有图片与 GIF 展示，会话切换和失败时不应显示旧会话的结果，也不自动重放结果不明的发送或收藏操作。

表情缩略图和已读目录页不设七天期限；聊天图片、按需取得的原图以及允许存储的外链图片按最后访问时间七天惰性清理，缓存共用 Kingfisher 约 1 GiB 的异步容量目标，系统也可能提前清理。受控服务的设备副本是用户要求的应用数据，HTTP 共享缓存策略保持不变；第三方外链尊重明确的禁止缓存指示。缓存不包含仍待发送或结果未确认的图片；清理不会操作服务端数据或用户相册。是否能命中和后台更新仍须在设备验证。

需在具备现有 iOS 构建环境的机器上运行 CFL fake 测试并构建，在设备上验收面板、键盘切换、原附件与语音交互、收藏及 GIF。此变更在 Linux 宿主未执行 Swift 构建或测试，线上 CFL 部署版本亦未验证。
